# 条目记忆卡片 UI 重构设计

日期: 2026-05-21

## 问题

当前 `EntryMemoryItemWidget` 存在以下问题：

1. **长文本溢出**：连续字符（URL、API Key）无法强制换行，遮挡右侧按钮
2. **按钮始终占位**：编辑/删除/开关三控件永久占位，视觉噪音大
3. **无视觉层次**：平铺列表行，不像独立卡片
4. **编辑体验差**：需点击编辑按钮才进入编辑模式

## 重构方案：悬浮操作卡片

### 布局结构

```
┌─ 圆角卡片 (border-radius:8px) ──────────────────┐
│  ✓  内容文本全宽 (padding-left:40px给开关留位)    │
│     word-break: anywhere 长字符强制换行             │
│                              [✏️][🗑️] ← hover浮现 │
└──────────────────────────────────────────────────┘
```

- 卡片用 `QFrame` 实现，圆角边框+微内边距
- 左侧圆形开关指示器（绝对定位 left:10px, 垂直居中）
- 内容文本区全宽，`overflow-wrap: anywhere` 强制换行
- 编辑/删除按钮 hover 时右上角浮现
- 不显示来源信息（source 参数保留但不在 UI 展示）

### 交互状态

| 状态 | 视觉 | 行为 |
|------|------|------|
| 常规 | 灰色边框，按钮隐藏 | — |
| Hover | 蓝色边框高亮，右上浮现操作按钮 | — |
| 选中 | 蓝色边框持续高亮 | 单击触发 |
| 禁用 | 左侧圆圈空心，文字半透明+删除线 | 单击圆圈切换 |
| 编辑态 | 内容区变为 textarea | 双击或点✏️进入 |

### 交互规范

**鼠标：**
- 单击 → 选中条目（蓝色边框高亮）
- 双击内容 → 进入行内编辑模式
- 单击圆形指示器 → 切换启用/禁用
- hover 条目 → 边框高亮 + 右上浮现操作按钮
- 🗑 按钮 → 删除条目
- ✏️ 按钮 → 进入编辑模式

**键盘（编辑态）：**
- `Ctrl+Enter` → 保存编辑
- `Esc` → 取消编辑，恢复原文
- 失去焦点 → 自动保存
- 编辑框自动适应内容高度，最大 200px 后可滚动

### 禁用状态样式

- 左侧指示器：空心圆圈，border-color:#555
- 内容文字：opacity:0.4, text-decoration:line-through
- 操作按钮：hover 时仍然浮现（允许重新启用或删除）

### 实现要点

1. **EntryMemoryItemWidget** 从 `QWidget` 改为基于 `QFrame` 的卡片样式
2. 用只读 `QPlainTextEdit`（`WrapAtWordBoundaryOrAnywhere`）替换 `BodyLabel`，解决长文本换行问题
3. 左侧开关改用自定义绘制的圆形指示器（`paintEvent`），单击切换 `enabled` 状态
4. 编辑/删除按钮用 `TransparentToolButton`，通过 `enterEvent`/`leaveEvent` 控制显示
5. 双击内容区 `QPlainTextEdit` 进入编辑态，显示 `TextEdit` 编辑框
6. 卡片样式使用 `design_tokens.py` 中的颜色常量保持一致性

### 不在范围内

- 条目记忆 Tab 的添加输入框（保持现有设计）
- 列表容器的样式（仅改列表项）
- 其他两个 Tab（项目笔记、关键文档）不受影响
