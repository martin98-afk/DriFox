# workflow

受限 Python 脚本编排子智能体。模型一次性写出编排程序（条件/循环/并行扇出），
脚本经钩子派发子智能体，前台阻塞返回原子结果。

## 用法

- `agent(prompt, agent=角色)` 跑一个子智能体，返回最终文本，失败返回 None
- `parallel([零参函数])` 并发执行并等全部（屏障）
- `pipeline(items, *stages)` 无屏障流水线，每项独立流过各阶段
- `phase(title)` / `log(msg)` 进度记录
- 最终结果赋给 `result` 变量

## 与其他工具分工

- 一两个委派 → `subagent_para`
- 固定依赖图 → `subagent_dag`
- 条件/循环/数据变换的大规模扇出 → `workflow`

## 配置

设置卡可调：并发上限 / 总数上限 / 单次项数 / 总时长 / 默认角色 / 结果字符上限。
环境变量 → 设置值 → 内置默认，三级链。
